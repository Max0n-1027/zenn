## 構成

- クライアントPC
  - OS : Kubuntu 26.04 LTS
  - クライアント:Remmina
- 踏み台サーバー
  - OS : Almalinux 10.2
- 接続先PC(例)
  - OS : Windows 11 26H2

## 前提条件
- Cloudflare Tunnelが利用できる状態
  - Cloudflareアカウントを所有していること
  - ドメインを取得していること
- ローカル環境で踏み台サーバーへsshできていること
- ローカル環境の他PCへsshポートフォワーディング経由で接続できていること

## 踏み台サーバーの設定

### cloudflaredのインストール
以下のコマンドでcloudflaredをインストールする
```bash
# リポジトリを追加する
sudo dnf config-manager --add-repo https://pkg.cloudflare.com/cloudflared.repo
# cloudflaredをインストールする
sudo dnf install cloudflared

# インストールされているか確認
cloudflared --version
# cloudflared version 2026.11.1 (built 2026-11-17-15:04 UTC)
```

### トンネルの作成
以下のコマンドでcloudflaredをインストールする
```bash
cloudflared tunnel login
# Please open the following URL and log in with your Cloudflare account:

#ログインURLが表示される

# Leave cloudflared running to download the cert automatically.
# 2026-11-17T17:37:36Z INF You have successfully logged in.
# If you wish to copy your credentials to a server, they have been saved to:
# /home/user/.cloudflared/cert.pem


cloudflared tunnel create {トンネル名}
# Tunnel credentials written to /home/user/.cloudflared/{トンネル ID}.json. cloudflared chose this file based on where your origin # certificate was found. Keep this file secret. To revoke these credentials, delete the tunnel.

# Created tunnel Bastion01 with id {トンネル ID}

cloudflared tunnel route dns {トンネル ID} {登録するサブドメイン.ドメイン}
# 2026-11-17T17:41:41Z INF Added CNAME {登録するサブドメイン.ドメイン} which will route to this tunnel tunnelID={トンネル ID}
```

### 通信設定を記載する
1. コンフィグファイルを作成する
```bash
sudo mkdir /etc/cloudflared/
sudo vi /etc/cloudflared/config.yml
```
2. コンフィグファイルに設定を記載する
```yaml
tunnel: {トンネル ID}
credentials-file: /home/user/.cloudflared/{トンネル ID}.json

ingress:
    - hostname: {登録するサブドメイン.ドメイン}
      service: ssh://localhost:22
    - service: http_status:404

```

### cloudflaredをサービス登録する
```bash
sudo cloudflared service install
sudo systemctl restart cloudflared
```

### クライアントPCの設定
### cloudflaredのインストール
以下のコマンドでcloudflaredをインストールする
```bash
# Add cloudflare gpg key
sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null

# Add this repo to your apt repositories
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared noble main' | sudo tee /etc/apt/sources.list.d/cloudflared.list

# install cloudflared
sudo apt-get update && sudo apt-get install cloudflared

# インストールされているか確認する
cloudflared --version
```

### ssh_configの設定
`~/.ssh/config`に次の設定を記載する
```bash
Host 接続名
    HostName {登録するサブドメイン.ドメイン}
    User user
    ProxyCommand cloudflared access ssh --hostname %h
    IdentityFile ~/.ssh/IdentityFile
```

### Remminaで接続してみる
SSHトンネルに設定したtunnelのアドレスを指定してリモート接続する他PCに接続してみる

## Cloudflareの設定(推奨)
設定しなくて通信できるがアドレスさえ知っていればだれでも接続可能になるため設定を推奨
1. Zero Trust → Accessコントロール → アプリケーション → 新規アプリケーションを作成
2. アプリケーションを追加するからセルフホストとプライベートで続行
3. パブリックホスト名に先程設定した`{登録するサブドメイン.ドメイン}`を入力する
4. Accessポリシーから新しいポリシーを作成をクリック
5. ポリシー名とポリシールールを設定してポリシーを保存
6. 元の画面で保存して設定完了(セッション期間等適宜設定すること)
